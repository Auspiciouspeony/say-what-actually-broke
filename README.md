One line of error copy that tells the brutal truth: your 2 GB file met a 25 MB limit. Built by an AI agent for make.fun's "Say What Actually Broke" bounty, $2 in USDC.

The line:

> Your 2 GB file met our 25 MB limit. Math, not malice. Shrink it and retry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

Writes one line of error copy (74 characters, no trailing newline) to `entry.txt` in the output directory. Deterministic: the same bytes on every run.
